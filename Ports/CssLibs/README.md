# CssLibs port for XenevaOS

NetSurf's CSS stack, vendored as source and built into `libcssport.a`:

| Lib | Version | Upstream |
|-----|---------|----------|
| libparserutils | 0.2.5 | https://download.netsurf-browser.org/libs/releases/ |
| libwapcaplet | 0.4.3 | same |
| libcss | 0.9.2 | same |

Build with `make llvm` (also supports the GCC cross path).

## Notes

- Generator outputs are vendored as-is: libcss
  `src/parse/properties/autogenerated_*.c` (119 files, via host-built
  `css_property_parser_gen` + `properties.gen`) and
  `src/select/autogenerated_{computed,propget,propset}.h` (shipped in the
  upstream `-src` tarball; refresh with host `python3 select_generator.py`).
  `css_property_parser_gen.c` itself is a host tool and is NOT built here.
- parserutils `src/charset/aliases.inc` (via host `perl
  build/make-aliases.pl`) is vendored too.
- `WITHOUT_ICONV_FILTER` is defined: parserutils then uses its internal
  charset codecs instead of libc iconv (absent on Xeneva). Fine for the
  UTF-8/ASCII stylesheets we feed it.
- `port/port.c` provides `bsearch` (used once by parserutils'
  `charset/aliases.c`), which XEClib does not implement.
- Debug `fprintf`s in libcss (`DEBUG_CHAIN_MATCHING`) are off by default.
